Survey / Contributor Mode

Opt in to help map the long tail of Axis devices. When enabled, ADMZ surveys the devices it can reach (read-only API discovery), redacts everything site-sensitive, and submits new findings to {{ repo }} as a pull request for review. Off by default.

What is collected and sent
  • Device identity: model, firmware, SoC, hardware id, part number.
  • The API surface: API ids/versions and OpenAPI schemas.
  • Serials are hashed by default (opt in to send raw).
What is never sent
  • Credentials or secrets of any kind.
  • Network/site config (hostname, IP, DNS, NTP, VLAN).
  • Geolocation, privacy-mask coordinates, overlay text, user names, or any live response values.
