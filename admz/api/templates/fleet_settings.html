Break-glass root password

The password ADMZ writes to root on every factory-defaulted device it provisions, before creating its own admz account. It is one value for the whole fleet, on purpose: keep it somewhere a person can find it, because it is how you get into a device by hand if ADMZ's database is ever lost. ADMZ never stores it per device and never shows it to the AI assistant.

Status {% if root_password_configured %} Set {% else %} Not set — factory-defaulted devices will not be provisioned until one is set. {% endif %}

Changing it does not change devices ADMZ has already provisioned. They keep the root password they were given; only devices provisioned after the change get the new value.
