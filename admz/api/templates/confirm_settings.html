Plaintext credential access

Device-account passwords are never displayed in the web UI or via REST, and no MCP tool returns them to an LLM. ADMZ reads them from the secrets backend only at execution time. For ad-hoc access, create_temp_credentials mints a short-lived device-side account instead. Revealing fleet-level admin secrets (API keys) requires membership in a reveal group.
