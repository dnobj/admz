# Radar

VAPIX® Radar APIs are a set of application programming interfaces (API) for the Axis security radars. The APIs showcase to the user how to set up the radar and integrate multiple Axis features with it.

The following list contains helpful API:s that can be used together with the Radar API:s

-   [Edge storage API](/vapix/network-video/edge-storage-api/)
-   [Entry service API](/vapix/network-video/entry-service-api/)
-   [Event and action services](/vapix/network-video/event-and-action-services/)
-   [Event data streaming](/vapix/network-video/event-data-streaming/)
-   [Input and outputs](/vapix/network-video/input-and-outputs/)
-   [Network settings](/vapix/network-video/network-settings/)
-   [Network settings API](/vapix/network-video/network-settings-api/)
-   [On-screen controls](/vapix/network-video/on-screen-controls/)
-   [Overlay API](/vapix/network-video/overlay-api/)
