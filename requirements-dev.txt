# Bounds follow the rule stated at the top of requirements.txt: `>=F,<C` where C
# is the next boundary above the version currently installed, on the package's
# own breaking axis. Floors raised to the installed major only where they sat
# below it — a floor under the installed major lets a resolver backtrack install
# a version this suite cannot run.
#
# These matter as much as the runtime bounds: a test-tool major that lands
# mid-week turns CI red on an unchanged commit, and there is no way to tell that
# apart from a real regression. That is the whole complaint in #227.
